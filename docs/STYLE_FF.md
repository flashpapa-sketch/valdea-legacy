# 文体ガイド（Fighting Fantasy 風）

「ヴォルカネスの迷宮」の本文・ルール説明・自動挿入される指示文を書くときの基準。
文体・構成・ルール説明の作法だけを借りる。原作の固有名詞や原文は使わない。

## 1. 用語表

| 用語 | 英語表記 | 意味 | 実装上の扱い |
|---|---|---|---|
| 技術点 | SKILL | 戦闘と技術試験の力量。1d6＋6 | 戦闘の攻撃力に加算 |
| 体力点 | STAMINA | 生命力。0で死亡。2d6＋12 | 戦闘ダメージで減少 |
| 運点 | LUCK | 幸運。1d6＋6 | 運試しで使うたび−1 |
| 運試し | Test your Luck | 2D6の合計が運点以下なら成功 | `luckCheck`。成功・失敗とも運点−1 |
| 技術試験 | Test your Skill | 技術点を基準にした判定 | `skillCheck` |
| 戦闘 | Combat | 2D6＋技術点の比較を繰り返す | `startCombat` / `c-atk` |
| 食料 | PROVISIONS | 1食で体力点＋4。戦闘中は食べられない | `useFood` |
| 持ち物 | Backpack | 最大10個 | `addItem` |
| 道具 | Items | 戦闘中の「道具を使う」で使う | 固いパン・テニスタの木の実・回復薬 |
| 猿の右手 | Monkey's Paw | 一度だけ使える切り札。2D6の出目で効果が決まる | `MONKEY` |
| 冒険者シート | Adventure Sheet | 能力値・所持品・経験値を記録する紙（画面上では状態欄） | 状態サイドバー |

呼び方: 「体力」と略さない（体力点と書く）。「HP」「MP」は使わない。

## 2. 文末指示の定型

パラグラフ末尾の指示は `injectFFChoiceHints()` が自動で付ける。本文の選択肢ボタンの文言は次の形に揃える。

- 戦闘: `技術点 X、体力点 Y。<b>敵名</b>と戦え。勝てば先へ進め。`
- 運試し: `運試しをせよ（2D6の合計が運点以下なら成功）。成功なら○○へ、失敗なら△△へ進め。`
- 技術試験: `技術試験をせよ。`
- 通常の分岐: `「選択肢の文言」なら○○へ進め`

選択肢ボタンの文言は、行動そのものを短く書く（例: 「扉を開ける」「別の入口を探す（運試し）」）。
運試しや戦闘の選択肢には、ボタン側にも「（運試し）」などを明記する。

## 3. 本文の書き方

- 二人称（「あなた」）・常体（「〜だ」「〜する」）で書く。敬体（「です・ます」）は使わない。
- 一文を短く切る。一段落は二〜四文まで。
- 擬音・感嘆符（！）・「……」の多用を避ける。感情は行動と状況で示す。
- 選択肢は「何をするか」を書く。結果は書かない（結果は次のパラグラフで描く）。
- 冒頭の一文で場面を決める（「街門が近づく」「扉の向こうから笑い声がした」）。
- 数字は本文中で漢数字（一、二、十）を基本とする。ルール表の数字も同じ。

## 4. 禁止事項

- 遷移先 ID（`goto('…')` の引数）を文章のために変えない。
- ルール数値（技術点・体力点・運点・食料の回復量・持ち物の上限）を実装と食い違えて書かない。数値を書くときは `game.html` の `startCombat` / `luckCheck` / `useFood` / `addItem` / `LVS` を確認する。
- 原作の固有名詞（タイタン、アランシア、ザゴール等）や原文の引用を使わない。
- 英訳（`PARA_EN` / `CHOICES_EN`）が併記されている段落は、日本語を変えたら英訳も直す。
- 「〜なら○○へ進め」の正規表現（`injectFFChoiceHints` 内の `startCombat` / `luckCheck` / `skillCheck` / `goto` / `payGoto` の抽出）を壊す書き換えをしない。文字列リテラルだけを変える。

## 5. 定番シチュエーションの例

- 街門・入口: 門番や掲示板で情報を得る。「引き返す」選択肢を一つ用意する。
- 酒場・宿: 噂話を聞く。金貨を払う選択肢（`payGoto`）を使うときは金額を本文に書く。
- 隠し通路・罠: 運試しで成否を分ける。失敗時も進行できるように遷移を用意する。
- 遺跡の番人・ボス前: 戦闘前に戦う／逃げる／道具を使うの選択肢を並べる。食料は戦闘中に使えないと本文で示す。
- 分岐の合流: 「仲間と話す」など、仲間の有無で文章が変わる場合は `hasFlag` で切り替える（既存の表示切替を踏襲する）。
- エンディング: 結末を簡潔に書き、最後は「あなたの冒険はここで終わった」型の一文で締める。
