# 進捗記録の設定手順（Googleスプレッドシート＋Apps Script）

ゲームを遊ぶと、どの段落まで進んだかを匿名で1行ずつシートに記録します。
記録内容：段落番号・体力・最大体力・金貨・言語・端末の種類（PC／モバイル）・ブラウザごとのランダム番号。
**名前・メール・IPは記録しません。**

## 1. スプレッドシートを作る

1. Google スプレッドシートで空のブックを作る（名前例：「ヴォルカネス進捗記録」）。
2. 何も入力しなくてよい（シート「progress」はスクリプトが自動で作ります）。

## 2. スクリプトを貼る

1. 上のメニュー「拡張機能」→「Apps Script」を開く。
2. 初期の `コード.gs` の中身をすべて消し、`progress-log/Code.gs` の内容を貼り付ける。
3. 保存（Ctrl+S）。

## 3. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」。
2. 種類：「ウェブアプリ」。
3. 次のユーザーとして実行：「自分」。
4. アクセスできるユーザー：「**全員**」（ゲームからの匿名送信を受けるため）。
5. 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー。
6. 初回は「承認」が出ます。自分のアカウントで許可してください。

## 4. URLをゲームに設定する

コピーしたURLを私（Claude）に渡してください。`game.html` の `GAS_LOG_URL` に入れて公開します。
URLが空の間は、ゲームは何も送信しません（今の状態）。

## 5. 動作確認

- 公開後にゲームで数段落進む → シート「progress」に行が増えていれば成功。
- 増えない場合：デプロイのバージョンが「最新」か、アクセス範囲が「全員」かを確認。

## 注意

- URLを知っている人は誰でもこの記録に書き込めます。URLを公開しすぎないでください（ゲーム内に埋め込まれる分は仕方ありません）。
- 遊ぶ人に「進捗を匿名で記録している」ことを伝えてください。
- 記録の見方：シートの「段落」列で、どこまで進んだか・どこで止まったかを確認できます。
